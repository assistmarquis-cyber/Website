# Alan research agent

Marquis's evidence base for Alan. Files:
- `AGENT.md` how the daily run works and the rules (no fabricated research)
- `library.json` verified sources and what each one supports
- `loops.json` the mindset architecture, negative loops and the strategy for each, mapped to Marquis's frameworks
- `frameworks.md` how the agent reads his frameworks
- `queue.md` what to look up next
- `digests/` one note per daily run
- `check.mjs` run `node research/check.mjs` to validate

Everything here is plain files owned by Marquis, so it moves with the repo.
